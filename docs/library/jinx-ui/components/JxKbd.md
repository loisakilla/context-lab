Клавиша в тексте: обозначение горячих клавиш и сочетаний. Для сочетания ставьте несколько элементов подряд.

## Props
- children: название клавиши

## Examples
### Сочетание клавиш в подсказке
```tsx
<span>
  Сохранить: <JxKbd>Ctrl</JxKbd> <JxKbd>S</JxKbd>
</span>
```
