Ползунок для выбора числа в диапазоне: громкость, масштаб, бюджет. Управляемый через `value` и `onValueChange`, неуправляемый — через `defaultValue`.

## Props
- value: текущее значение в управляемом режиме
- defaultValue: начальное значение в неуправляемом режиме
- onValueChange: вызывается при изменении значения
- unit: единица измерения рядом со значением
- label: подпись над ползунком
- showOutput: показать текущее значение рядом с подписью

## Examples
### Бюджет контекста
```tsx
<JxSlider label="Бюджет контекста" defaultValue={2500} unit="ток." showOutput />
```
