Хлебные крошки: путь от корня раздела до текущей страницы. Элемент без `href` считается текущим и ссылкой не становится.

## Props
- items: элементы пути, каждый с подписью `label` и необязательной ссылкой `href`
- separator: разделитель между элементами, по умолчанию стрелка

## Examples
### Путь до настроек проекта
```tsx
<JxBreadcrumbs
  items={[
    { label: 'Проекты', href: '/projects' },
    { label: 'Контекст', href: '/projects/context' },
    { label: 'Настройки' },
  ]}
/>
```
