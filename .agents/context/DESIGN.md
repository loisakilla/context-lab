# Визуальная система лаборатории

Источник: `apps/lab/src/app/globals.css`. Все значения — CSS-переменные на `:root`, компоненты ходят только через них.

## Тема

Тёмная, без переключателя. Основана на дефолтной тёмной теме HeroUI v3: иерархия строится слоями заливки, а не рамками и тенями. Теней нет вообще.

| Токен | Значение | Где |
| --- | --- | --- |
| `--bg` | `oklch(0.135 0.005 285.8)` | фон страницы |
| `--surface` | `oklch(0.208 0.006 285.9)` | карточки, панели |
| `--surface-2` | `oklch(0.262 0.006 286)` | поля ввода, треки, блоки кода, шапка таблицы |
| `--segment` | `oklch(0.34 0.008 286)` | выбранный сегмент, ховер поля |
| `--separator` | `oklch(0.25 0.006 286)` | линии внутри карточек и строк таблицы |
| `--fg` | `oklch(0.985 0 0)` | основной текст |
| `--muted` | `oklch(0.72 0.014 286)` | подписи, вторичный текст |
| `--dim` | `oklch(0.6 0.012 286)` | метаданные, служебные строки |

## Акцент и статусы

`--accent: oklch(0.62 0.195 253.8)` — синий HeroUI. Только заливка: первичная кнопка, текущий раздел в шапке, кольцо фокуса, знак логотипа. Для акцентного текста отдельный `--accent-text: oklch(0.78 0.12 253.8)`, потому что заливочный синий не даёт 4.5:1 на тёмном.

Статусы: `--success` (прошло), `--warning` (частично), `--danger` (ошибки). У каждого есть `-soft` — та же краска с альфой 0.14 под чипы.

## Типографика

Inter 400/500/600 для всего, JetBrains Mono 400/500 для кода, идентификаторов и чисел. Моноширинный всегда с `tabular-nums`, чтобы колонки цифр выравнивались.

Шкала фиксированная: 30/20/15 для h1–h3, 16 для текста, 14 для контролов, 13 для подписей, 12.5 для чипов. Заголовки `-0.015…-0.022em`, `text-wrap: balance`. Длина строки прозы ограничена 68ch (`.lede`) или 80ch.

## Радиусы

8 — мелкое (ссылки шапки, сегменты, ячейка таблицы), 12 — поля, кнопки, блоки кода, 14 — карточки и кадр превью, 999 — чипы. Выше 14 не поднимаемся.

## Компоненты

- `.card` — поверхность без рамки и тени, 20–24 padding. `.card__head` отбивает заголовок волосяной линией.
- `.input` — заливка `--surface-2`, прозрачная рамка, на фокусе синяя рамка плюс кольцо `--accent-soft` 3px.
- `.btn` — высота 38, три варианта: `primary` (заливка акцентом), `flat` (нейтральная заливка), `ghost` (прозрачная). На `:active` — `scale(0.97)`.
- `.seg` — сегментированный переключатель: трек `--surface-2`, выбранный элемент `--segment`. Используется для режима контекста, движка прогона и переключателей в реестре правил.
- `.chip` — пилюля с мягкой заливкой статуса. Вердикт прогона, правило линтера, выдуманный пропс.
- `.table` — шапка на `--surface-2`, строки разделены `--separator`, ячейка с прогоном целиком является ссылкой и подсвечивается на ховере.
- `.note` — мягкая плашка статуса вместо рамки-обводки.

## Движение

Одна кривая `--ease: cubic-bezier(0.23, 1, 0.32, 1)` и одна длительность `--fast: 150ms` на цвет и фон, 160ms на `transform`. Анимируются только `transform`, `background-color`, `color`, `opacity`. При `prefers-reduced-motion` всё схлопывается в 1ms.

## Сетка

`.wrap` — 1120px, `--wide` 1560px для страницы сравнения, `--narrow` 880px. Боковые поля 16px на телефоне, 24px от 640px. Шапка `.bar` липкая, переносит навигацию на вторую строку на узком экране.

## Граница с Jinx UI

Оболочка лаборатории не подключает CSS Jinx UI. Библиотека живёт только внутри `<iframe>` превью со своей темой `dark` и стилем `brutal`. Это единственное громкое место на странице, и так задумано.
