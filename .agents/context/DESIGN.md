# Визуальная система лаборатории

Лаборатория одета в саму Jinx UI: `data-theme="light"`, `data-style="brutal"` на `<html>`. Своих цветов, радиусов и теней у неё нет — всё приходит из `@jinx-ui/tokens` и `@jinx-ui/core`. Файл `apps/lab/src/app/globals.css` добавляет только то, чего в библиотеке нет: раскладку страницы, шапку, ячейку таблицы и пару текстовых утилит, и все они ссылаются на `var(--jx-*)`.

## Тема: brutal light

| Токен | Значение | Где |
| --- | --- | --- |
| `--jx-bg` | `#f5f2e9` | фон страницы, бумага |
| `--jx-surface` | `#ffffff` | карточки, поля, блоки кода |
| `--jx-surface-2` | `#f0ebdb` | шапка таблицы, инлайновый код |
| `--jx-border` | `#1a1726` | рамки 2px, линии |
| `--jx-text` | `#1a1726` | весь текст |
| `--jx-text-3` | `#6e6386` | подписи и метаданные |
| `--jx-accent` | `#1a1726` | заливка первичной кнопки |
| `--jx-accent-ink` | `#f5ff3d` | текст на первичной кнопке |
| `--jx-shadow-sm` | `4px 4px 0 #1a1726` | жёсткая тень вместо размытой |
| `--jx-r` | `4px` | радиус везде |

Шрифт один: JetBrains Mono. Brutal переводит на моноширинный и текст, и заголовки, заголовки идут капслоком. Fraunces остаётся только в логотипе.

## Компоненты

Всё, что есть в библиотеке, берётся из библиотеки, а не пишется заново:

| Место | Компонент |
| --- | --- |
| выбор задачи, модели, режимов сравнения | `JxSelect` |
| формулировка задачи | `JxTextareaField` |
| ключ API | `JxInputField`, `JxCheckbox` |
| режим контекста, движок прогона | `JxTabs` |
| запуск, отмена, фильтры реестра | `JxButton` |
| вердикт, правило линтера, выдуманный пропс | `JxBadge` |
| ошибка прогона, отсутствующая запись | `JxAlert` |
| матрица прогонов | `JxTable` |
| карточки и секции | класс `.jx-card` |

`apps/lab/src/components/ui.tsx` — тонкая прослойка над ними: она держит один и тот же интерфейс для страниц (`Select`, `Textarea`, `Tabs`, `Button`, `Badge`, `Note`, `Stat`) и переводит тона лаборатории в тона библиотеки.

## Что добавлено поверх библиотеки

- `.wrap` — контейнер страницы: 1120px, `--wide` 1560px для сравнения; поля 16px на телефоне и 28px от 640px.
- `.bar` — липкая шапка с логотипом `.jx-logo` и навигацией; на узком экране навигация переносится на вторую строку.
- `.scroller` — горизонтальная прокрутка для `JxTabs`: пять режимов контекста не помещаются в 390px и должны прокручиваться, а не растягивать страницу.
- `.cell` — содержимое ячейки матрицы целиком является ссылкой на прогон и подсвечивается `--jx-accent-soft`.
- `.code` — блок кода на токенах библиотеки с переносом длинных строк.
- `.stat`, `.muted`, `.dim`, `.mono`, `.lede`, `.rule` — текстовые и разделительные мелочи.

## Кадр превью

Сгенерированный компонент рендерится в `<iframe>` с тем же `data-theme="light" data-style="brutal"`, что и страница: результат выглядит как часть интерфейса, а не как чужая вставка. Рамка кадра — 2px `--jx-border`, высота от 200px до 1200px по замеру содержимого, включая оверлеи модальных окон.

## Известные ограничения библиотеки

1. Тона `success`, `warning`, `danger` заданы один раз под тёмную тему; на светлом фоне `#6bd97a` даёт около 1.9:1, то есть бейдж «проверки пройдены» читается плохо. Нужны значения под `[data-theme="light"]`.
2. `.jx-chip--active` перекрывается скином brutal (`[data-style="brutal"] .jx-chip` специфичнее), поэтому активный чип неотличим от обычного. Из-за этого фильтры в реестре правил сделаны на `JxButton`, а не на `JxChip`.
